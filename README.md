# 📰 News App

A responsive React-based News App that fetches and displays the latest news using the News API.

## 🚀 Features

- Latest news headlines
- Category-wise news
- Responsive user interface
- Loading spinner
- Fast and easy to use

## 🛠️ Tech Stack

- React.js
- JavaScript
- Bootstrap
- News API

## 📥 Installation

1. Clone the repository:

```bash
git clone https://github.com/payal-jambhekar/News-app.git
```

2. Go to the project folder:

```bash
cd News-app
```

3. Install dependencies:

```bash
npm install
```

4. Start the application:

```bash
npm start
```

5. Open your browser and visit:

```
http://localhost:3000
```
